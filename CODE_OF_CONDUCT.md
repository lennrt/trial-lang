# Code of Conduct

triallang is a small project, and this document is short on purpose.

## Expectations

Everyone participating in issues, pull requests, reviews, and discussions is
expected to:

- Be respectful. Disagree with ideas, not people.
- Assume good faith and ask before concluding.
- Keep feedback specific and about the work.
- Respect maintainers' decisions about scope. A declined proposal is not a
  judgment of its author.

Harassment, personal attacks, discriminatory remarks, and publishing others'
private information are not acceptable anywhere in the project's spaces.

## Reporting

Report conduct concerns privately to the maintainer at
[lrudolph@hmc.edu](mailto:lrudolph@hmc.edu). Reports are handled privately,
with disclosure limited to what is needed to resolve the concern.
Non-sensitive process questions can be raised in a GitHub issue.

## Enforcement

Maintainers may edit or remove comments, close discussions, and temporarily or
permanently block participants who violate these expectations. Where possible,
a warning comes first.

This document is informed by the
[Contributor Covenant](https://www.contributor-covenant.org/), which is a good
reference for the fuller version of these principles.
